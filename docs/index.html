a ticket to everywhere.

moonucd is the Unicode Character Database for MoonBit — a passport office for every code point of Unicode 17.0.0, from Hangul to Devanagari, emoji to the unassigned. Type a character and this page asks the compiled library what it is: its category, script, block, age, width and line-break class. No server, no guesswork: the very tables that ship in the package run right here in your browser.

What ships

Nine small packages

The root package holds the general character facts; the rest are opt-in sub-packages you import only when you need them. Everything runs on every MoonBit backend — native, wasm, wasm-gc and js.

The core package

// what a character is
@moonucd.category('中')          // Lo
@moonucd.bidi('א')               // R
@moonucd.numeric('٣')            // Some(Decimal)
@moonucd.has('é', Alphabetic)    // true

// changing case
@moonucd.upper("straße")         // "STRASSE"
@moonucd.lower("ΟΔΟΣ")           // "οδος"

Line breaking, validated

The linebreak package is checked against the full LineBreakTest.txt — 19,338 cases — at zero conformance errors, on all four backends. 

// where a line may wrap
@linebreak.linebreaks("The quick 中文 fox")
// ["The ", "quick ", "中", "文 ", "fox"]
@linebreak.lb_property('中')    // ID

How it is made

Generated from the UCD

Every table is generated from the Unicode Character Database 17.0.0 by the scripts in scripts/tables. They turn UnicodeData.txt, Scripts.txt, LineBreak.txt, EastAsianWidth.txt, emoji-data.txt, NormalizationTest.txt and the break tests into the run-length tables the library searches at runtime. A new Unicode release is a regeneration — the algorithm code does not change.

version() returns "17.0.0" from every package.
