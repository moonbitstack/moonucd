fnfold

pub fn fold(StringView) -> String

text case-folded with the full foldings, for caseless comparison.

fnfold_orbit

pub fn fold_orbit(Char) -> Array[Char]

Every character that folds to or from ch, itself included, ascending: the class a caseless match of one character has to cover.

test {
assert_eq(@moonucd.fold_orbit('K'), ['K', 'k', '\u{212A}'])
assert_eq(@moonucd.fold_orbit('ς'), ['Σ', 'ς', 'σ'])
assert_eq(@moonucd.fold_orbit('中'), ['中'])
}

fnsimple_fold

pub fn simple_fold(Char) -> Char

The simple case folding of ch: the one character it turns into when case stops counting, from the C and S classes of CaseFolding.txt. A code point that only has a longer fold, ß to ss, folds to itself, since one character cannot become two.

test {
assert_eq(@moonucd.simple_fold('A'), 'a')
assert_eq(@moonucd.simple_fold('ς'), 'σ')
assert_eq(@moonucd.simple_fold('ß'), 'ß')
assert_eq(@moonucd.simple_fold('1'), '1')
}

pub fn Script::extended_ranges(Self) -> Array[(Int32, Int32)]

The ranges where the script is one of the scripts a character is used with: Script_Extensions where the database writes one, and the script the character is listed under where it does not. A character shared between scripts changes hands, so this is not ranges plus more: the prolonged sound mark is Common on its own, and here it belongs to Hiragana and Katakana instead.

test {
let holds = fn(ranges : Array[(Int32, Int32)], cp : Int32) -> Bool {
for (a, b) in ranges {
if a <= cp && cp <= b {
return true
}
}
false
}
assert_true(holds(@script.Katakana.extended_ranges(), 0x30FC))
assert_true(holds(@script.Hiragana.extended_ranges(), 0x30FC))
assert_true(!holds(@script.Katakana.ranges(), 0x30FC))
}

The script called name — a long name ("Latin", "Old Italic") or a four-letter code ("Latn", "Ital"), matched the loose way of UAX #44 (LM3): case, spaces, underscores, hyphens and a leading "is" are ignored.

width

moonbitstack/moonucd/width

Terminal cells and East Asian Width.

fneast_asian_width

pub fn east_asian_width(Char) -> Eaw

The East Asian Width of ch (see Eaw).

fntext_width

pub fn text_width(StringView, ambiguous? : Int32) -> Int32

The number of terminal cells s occupies, or -1 when it holds a control character. A Zero Width Joiner hides the character after it, so an emoji sequence counts once, and a Variation Selector 16 (U+FE0F) after a character that takes an emoji presentation widens it by one cell. ambiguous is as for width.

fnversion

pub fn version() -> String

The version of the Unicode Character Database the width data comes from.

fnwidth

pub fn width(Char, ambiguous? : Int32) -> Int32

The number of terminal cells ch occupies: -1 for C0 and C1 control characters, 0 for NUL, combining marks and other zero-width code points, 2 for Wide and Fullwidth code points, and 1 otherwise. ambiguous is the width an East Asian Ambiguous character takes where it would otherwise take one cell; a CJK terminal draws them two wide.

enumEaw

The East Asian Width of ch, the UCD ea property: a code point is Wide (W) or Fullwidth (F) in two cells, Narrow (Na) or Halfwidth (H) in one, Ambiguous (A) depends on context, and Neutral (N) defaults to one. Unassigned code points and surrogates are Neutral.

  • NaNarrow
